## Como se tornar um mantenedor

1. Contribua ativamente com PRs e code reviews por pelo menos 3 meses
2. Demonstre conhecimento do código e das práticas do projeto
3. Seja convidado por um mantenedor existente
4. Aceite o compromisso de revisar PRs semanalmente
